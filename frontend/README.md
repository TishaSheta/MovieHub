# MovieHub

1. Get a free API key at https://www.themoviedb.org/settings/api
2. `cp .env.example .env` and paste your key into `VITE_TMDB_KEY`
3. `npm install`
4. `npm run dev`

## Deploy
`npm run build`, then deploy `dist/` to Vercel or Netlify.
`vercel.json` and `public/_redirects` make React Router work on refresh.
